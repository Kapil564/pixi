THE MOTIVATION

Why Saira exists

The problem

  • Existing desktop voice assistants are tightly locked to proprietary cloud ecosystems — telemetry, mandatory accounts, and static cloud endpoints.
  • They break completely when cloud APIs are unavailable or when your internet drops.
  • Users have zero local control over which speech, intent, or text-to-speech provider is doing the work.

What Saira does instead

  • Architected around a modular, local-first engine with a central orchestrator.
  • Pluggable STT / LLM / TTS providers with automatic fallback for 100% offline operation.
  • Long-term memory stored locally in SQLite (%APPDATA%\Saira\assistant.db) and human-editable Markdown memory files.

DEEP OS INTEGRATION

Native to Windows

Tray app, global hotkey & autostart

Runs quietly in the Windows System Tray. Press Ctrl+Shift+Space anywhere across the OS to summon Saira immediately. Configured to auto-start on boot via openAtLogin.

Frameless overlay & OS notifications

Frameless, transparent, always-on-top window overlay for both the Catppuccin widget and pixel mascot. Native Windows desktop popups powered by node-notifier.

Sleep, wake & unlock reminder checks

Monitors system sleep, wake, and screen-unlock events in real time to scan %APPDATA%\Saira\assistant.db and surface overdue reminders as soon as you unlock your device.
