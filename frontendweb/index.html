about.txt

pixi is a native Windows voice assistant built with Electron, React, and TypeScript. It answers with the LLM of your choice, speaks back in a voice you pick, and remembers everything as plain Markdown files on your own disk.

  • 100% offline mode — zero data ever leaves your PC.
  • Cloud keys fully optional: OpenAI, Gemini, Groq, Fish Audio, ElevenLabs, Azure.
  • Wake it with "Hey pixi" or Ctrl+Shift+Space.
  • Reminders, to-dos, and long-term memory stored locally in SQLite.
  • Open source under the MIT license.
The gap

What Windows was missing

Windows shipped Cortana for years, then quietly retired it. Users were left with a hole where an assistant should live.

the-gap.txt
  • Cortana is gone. Microsoft retired its built-in assistant with no replacement.
  • Cloud lock-in. Other assistants demand accounts, telemetry, and closed ecosystems.
  • Internet dependency. Cloud-only voice AI dies the second your connection drops.
  • Zero local control. No way to choose who does the speech, the thinking, or the voice.
  • No memory you can read. Preferences locked in vendor databases instead of files you own.
A new kind of window

How pixi creates a new window experience

Not a webpage in a frame — a floating native layer that hangs over Windows itself. Two UIs, one pixi, zero chrome.

▣ Pixel blob mascot

A lightweight, always-on-top pixel-art orb that sits on your desktop and reacts to its state — idle, listening, thinking, speaking — drawn live on canvas. You're watching a real one in the hero.

▣ Windows 11 widget bar

A frameless, Catppuccin-themed acrylic widget docked into your workflow: continuous voice-activity feedback, live logs, and instant provider switching. It feels native to Windows 11.

▣ Native integration

  • Lives in the system tray with autostart on login.
  • Ctrl+Shift+Space summons it from anywhere.
  • Speak over it to interrupt — instant, zero audio stacking.
  • Sleep / wake / unlock resurface overdue reminders.

Memory

It remembers — all on your disk

pixi learns your preferences, routines, and identity as you talk. Every fact it knows lives in plain files you can open, read, and edit.

how memory works
  • Profile, preferences, routines, people, and projects — each in its own Markdown file.
  • Extracted in the background while you chat, so it never blocks a reply.
  • Kept strictly inside %APPDATA%\pixi\ — no central server, no telemetry.
  • Every memory is a file you can open and edit any time.
